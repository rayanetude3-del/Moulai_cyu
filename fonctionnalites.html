Utilisation CLI et GUI

Mode CLI (console)

Le mode CLI permet d’utiliser l’application directement depuis le terminal en passant des arguments lors de l’exécution. L’utilisateur peut analyser soit un fichier MP3 unique à l’aide de l’option -f, soit un dossier contenant plusieurs fichiers MP3 avec l’option -d. Les métadonnées extraites sont affichées directement dans la console, ce qui permet une utilisation rapide et efficace.

L’option -o permet de sauvegarder le résultat du traitement dans un fichier de playlist, dont le format dépend le format choisie (par exemple .m3u8, .xspf ou .jspf). Quelques exemples d’utilisation sont :

  • -> java -jar cli.jar -f musique.mp3
  • -> java -jar cli.jar -d ./music -o playlist.m3u8
  • -> java -jar cli.jar -d ./music -o playlist.xspf

Le mode CLI est principalement destiné à un usage technique ou automatisé et met en avant la logique interne de l’application sans interface graphique.

Mode GUI (graphique)

Le mode GUI propose une interface graphique permettant une utilisation plus intuitive de l’application. L’utilisateur peut sélectionner un fichier ou un dossier à analyser via des fenêtres de sélection, visualiser les morceaux détectés dans un tableau et générer une playlist à l’aide de boutons. Ce mode est plus adapté à un usage interactif et visuel.

Le GUI repose sur les mêmes classes métier que le CLI, ce qui garantit un fonctionnement identique pour l’extraction des métadonnées et la création des playlists. La différence réside uniquement dans la manière dont l’utilisateur interagit avec l’application.

Comprendre le fonctionnement interne de l'Application

Fonctionnement général de l’application

Le fonctionnement de l’application repose sur une suite d’étapes logiques permettant de traiter efficacement les fichiers MP3 fournis par l’utilisateur.

  1. Sélection d’un fichier ou d’un dossier contenant des fichiers MP3
  2. Analyse automatique des métadonnées de chaque fichier détecté
  3. Stockage temporaire des informations extraites
  4. Génération d’une playlist à partir des fichiers analysés
  5. Export de la playlist dans le format choisi par l’utilisateur

Avantages de l’application

  • Gain de temps lors de l’organisation d’une bibliothèque musicale
  • Analyse automatique sans intervention manuelle
  • Compatibilité avec plusieurs formats de playlists
  • Utilisation possible en mode console ou graphique
  • Code structuré et conforme aux bonnes pratiques Java

Limites et évolutions possibles

Dans sa version actuelle, l’application se concentre exclusivement sur le traitement des fichiers MP3. Certaines fonctionnalités pourraient être ajoutées à l’avenir.

  • Prise en charge d’autres formats audio
  • Amélioration de l’interface graphique
  • Ajout de fonctionnalités de tri et de recherche avancée
  • Gestion des erreurs plus détaillée
